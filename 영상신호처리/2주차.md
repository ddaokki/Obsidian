## 1. 영상 처리 개요 (Page 1-2)
- **주제:** 화소(밝기) 값 변환 및 히스토그램 연산을 이용한 영상 처리.
- **명암도 변환 (Gray-level Transformation):** 입력 영상의 화소 값 $r$을 변환 함수 $T$를 통해 출력 화소 값 $s$로 매핑하는 과정 ($s = T(r)$).
    - **대조 강화 (Contrast Enhancement):** 특정 명암 범위를 넓히거나 좁혀 영상의 가시성을 높임.
## 2. 기본 명암도 변환 함수 (Page 3-6)
영상을 개선하기 위해 사용하는 세 가지 기본 함수 유형입니다.
- **반전 변환 (Negative Transformation):**
    - 공식: $T(r) = L - 1 - r$ (여기서 $L-1$은 최대 명암도).
    - 특징: 사진 인화의 네거티브 효과를 내며, 어두운 영역의 세부 정보를 찾는 데 유용함 (예: 유방암 진단 영상).
- **로그 변환 (Log Transformation):**
    - 공식: $T(r) = c \log(1 + r)$.
    - 특징: 입력의 좁은 범위인 낮은 어두운 값을 넓은 범위의 출력 값으로 확장함. 주로 푸리에 스펙트럼과 같이 동적 범위가 큰 영상을 표시할 때 사용됨.
- **거듭제곱 변환 (Power-Law/Gamma Transformation):**
    - 공식: $T(r) = c r^\gamma$.
    - **감마 교정 (Gamma Correction):** 장치(모니터 등)의 비선형적 반응을 보정하거나, 영상의 대비를 조절함.
        - $\gamma < 1$: 어두운 부분을 밝게 확장 (로그 변환과 유사).
        - $\gamma > 1$: 밝은 부분을 더 밝게, 전체적으로 대비를 높임.
## 3. 감마 변환 응용 사례 (Page 7-10)
- **CRT 장치 보정:** CRT 모니터는 일반적으로 1.8~2.5의 감마 값을 가지므로, 이를 상쇄하기 위해 역감마($\gamma = 0.4$) 변환을 적용함.
- **의료 영상 (MRI):** 척추 골절 MRI 영상에서 $\gamma$ 값을 조절하여 어두운 부분의 세부 디테일을 강조함.
- **항공 영상:** 너무 밝게 노출된 항공 영상에 $\gamma > 1$ (예: 3.0, 4.0 등)을 적용하여 대비를 개선함.
## 4. 조각별 선형 변환 함수 (Page 11-13)
특정 명암도 영역만을 선택적으로 변환하는 기법입니다.
- **대비 스트레칭 (Contrast Stretching):**
    - 낮은 대비의 영상을 입력받아 명암도 범위를 전체로 확장하여 선명하게 만듬.
- **임계값 처리 (Thresholding):**
    - 특정 값을 기준으로 영상을 흑백(이진화)으로 변환함.
- **명암도 슬라이싱 (Gray-level Slicing):**
    - 특정 범위 $[A, B]$의 명암도만 강조하고 나머지는 보존하거나 제거함.
    - **사례:** 대동맥 혈관 조영 영상(Angiogram)에서 특정 밝기 범위를 강조하여 혈관과 신장 부위만 선명하게 추출함
